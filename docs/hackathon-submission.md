# Hackathon submission checklist

**Deadline:** November 12, 2026, at 12:00 PM PST (2:00 PM CST).
[Official schedule](https://paypalaihackathon.devpost.com/details/dates).

Check items against the final submission. Requirements reviewed October 12, 2026.

## Submission deliverables

Based on the [official requirements](https://paypalaihackathon.devpost.com/) and
[rules](https://paypalaihackathon.devpost.com/rules).

- [ ] Working Suitefolk demo with central PayPal sandbox integration and a meaningful AI feature.
- [ ] Public repository contains the source, assets, complete run instructions, and a detectable [open-source license](../LICENSE).
- [ ] Judges can run the project from the repository or use a hosted demo, with clear instructions for any required demo access.
- [ ] Project description explains the audience, implemented features, and AI tools/models used and how they are used. Note significant hackathon-period updates if applicable.
- [ ] Public YouTube video under three minutes shows the working application; any third-party assets are used with permission.
- [ ] Description, video, and testing instructions are in English or include English translations.
- [ ] Eligibility and team representative, if applicable, confirmed against the rules.

## Suitefolk readiness checks

- [ ] [API and web verification](development.md#verify-changes) passes for the submission version.
- [ ] A fresh clone or clean session can reproduce the demo using the documented configuration and demo data.
- [ ] Demonstrated UI/API/database flow, payment success/cancellation/failure, and AI error handling have been exercised.
- [ ] Repository and video contain no real secrets; README, description, and video accurately reflect implemented features.

## Final handoff

- [ ] Recheck the rules and any selected sponsor-prize requirements; complete every required Devpost field, add repository/demo/video links, submit, and confirm submitted status before the deadline.
- [ ] Arrange free judge access through the end of judging on December 15, 2026, at 8:00 AM PST; include instructions for obtaining necessary test access.
